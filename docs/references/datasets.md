# Dataset and environment candidates

Selection occurs only after current license, provenance, quality, and contamination review. Candidate classes—not preapproved training assets—include:

- Reproducible open pretraining corpora with record-level or shard-level provenance and stable manifests.
- Public-domain and clearly licensed code/text/science sources with jurisdiction and collection dates.
- Partner datasets that can remain inside eligible islands with purpose-limited manifests.
- Synthetic corpora whose generator, prompts, parents, filters, and verifier evidence are recorded.
- Code environments with unit/integration tests, fuzzing, static analysis, compilers, and reproducible builds.
- Lean, Isabelle/HOL, Rocq/Coq, SAT/SMT, and proof-certificate environments.
- SPICE, CAD, physics, FEM/CFD, symbolic, and numerical simulator environments with version/tolerance evidence.

Evaluation suites need saturation, contamination, cultural/domain coverage, and dangerous-capability review. Hidden verifier tests are access separated from contributors. Dataset acceptance produces a signed version under [data governance](../data/data-governance.md), not an edit to this list.
