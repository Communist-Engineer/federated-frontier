# Ownership and the socialized-production contradiction

## Asset-rights matrix

| Asset | Rights that must be assigned separately |
|---|---|
| Code/control plane | copyright, maintainership, deployment, trademark, security authority |
| Data/manifests | source rights, custody, training purpose, derivative use, deletion, attribution |
| Model weights | possession, modification, training, serving, redistribution, release decision |
| Checkpoints/optimizer state | custody, access, recovery, merge and promotion |
| Contributions | compensation, attribution, IP grant, governance voice, audit |
| Research output | authorship, publication timing, patent, reproducibility artifacts |
| Brand/trademark | quality/safety representation and enforcement |

Decentralized compute plus centralized ownership can reproduce the original relation: many contributors bear cost and risk while a small entity owns weights, keys, revenue, and release. Tokens or reputation do not change that structure if decision and residual rights stay concentrated.

A genuine synthesis changes the asset and decision structure: for example, a foundation or member trust holds core public assets; operators receive bounded service mandates; contributors elect or select representation; data partners retain purpose constraints; release requires independent public-interest review; exit/portability prevents coordinator lock-in. Whether this is durable remains H8.

The alternative also has risks: diffuse ownership may slow urgent security action, deter capital, or make accountability ambiguous. Emergency powers therefore need narrow scope, expiry, audit, and post-hoc review.

FFI-GOV-003: contribution terms **MUST** state compensation, attribution, IP grant, model access, governance rights, and dispute process before work. FFI-GOV-004: weight release **MUST** identify the authorized body, evidence considered, dissent, and irreversible-risk rationale.
