# Theory of change

Fragmented compute has limited value when each owner lacks sufficient scale, shared data, verifiers, coordination, and durable rights. A federation can transform that condition if it creates four linked capacities:

1. low-communication optimization turns islands into a larger learning system;
2. verified inference and environments turn smaller machines into trustworthy experience producers;
3. provenance and reproducibility turn contributions into cumulative scientific knowledge;
4. federated ownership and governance keep the resulting productive capacity available to the community that creates it.

The theory fails if coordination and verification overhead consume the resource advantage, if heterogeneity destroys optimization quality, if security requires practical recentralization, or if legal ownership concentrates despite distributed production. The roadmap tests these failure modes before expanding scale.
