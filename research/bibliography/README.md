# Bibliography maintenance

The human-readable canonical bibliography is [docs/research/bibliography.md](../../docs/research/bibliography.md). This directory is reserved for future machine-readable exports such as BibTeX/CSL JSON produced from the same records, not a second hand-edited source.

When adding a source, record title, authors/organization, year/date, venue, DOI or arXiv identifier, stable URL, and access date for mutable web sources. Prefer primary sources and label vendor/blog claims. Update the evidence matrix claim, scale, topology, replication, limitations, and E0–E4 classification in the same change.
