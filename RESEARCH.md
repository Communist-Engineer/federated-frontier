# Research protocol

## Question

Can globally distributed, heterogeneous, independently operated compute create and continuously improve frontier-scale intelligence more effectively than the resources would in isolated projects?

## Method

1. Start with primary literature, official project reports, source repositories, standards, and hardware documentation.
2. Trace foundational claims backward and significant systems forward.
3. Record the actual model size, token budget, training stage, accelerator count, topology, trust assumptions, and network conditions.
4. Compare against a matched centralized or conventional distributed baseline.
5. Seek independent replication and negative results.
6. Assign E0–E4 evidence and a verbal certainty class.
7. Derive requirements and experiments only after evidence synthesis.

Research updates must change the [bibliography](docs/research/bibliography.md), [evidence matrix](docs/research/evidence-matrix.md), and [traceability matrix](docs/requirements/traceability-matrix.md) together whenever a conclusion changes architecture.

The search baseline closes on August 20, 2026. Future updates record their cutoff date and preserve prior conclusions through Git history.
